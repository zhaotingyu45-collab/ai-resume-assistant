# AI 求职经历资产管理助手

> 针对求职者反复改简历却容易夸大经历的问题，设计了基于个人经历证据的固定 Workflow，通过评测集与 badcase 迭代，在降低事实错误的前提下生成岗位定向简历。

个人离线 Demo · 固定 Workflow（非 Agent）· 前端单文件 · 无上线数据

## 如何运行

直接用浏览器打开 `index.html`。首次使用请在页面右上角「设置」中填写 DeepSeek API Key（仅存本机浏览器 localStorage，不上传、不写入代码）。

> 当前版本尚未接入大模型，可先体验经历库的新增 / 编辑 / 确认 / 删除与本地持久化。

## 核心设计

- **证据约束**：每条匹配结论必须引用经历原文，无引用判「暂无证据」，禁止仅凭关键词相似判定匹配。
- **固定 Workflow 而非 Agent**：六个节点（经历结构化 → JD 解析 → 经历匹配 → 缺口识别 → 简历生成 → 事实校验）各有明确输入输出，可逐节点审阅与归因。选择理由见 [DECISIONS.md](DECISIONS.md)。
- **事实校验兜底**：对照原始经历检查职责夸大、虚构数据、待确认被写成事实等风险；校验不能保证绝对正确，必须保留人工审核。

## 评测

评测集结构见 `samples.json`（待生成）。所有指标均来自自建探索性样本，样本量、打分口径与基线会随结果一并公开；未验证前一律标注「待验证」，不写具体数字。

## 边界声明

- 本项目为个人离线 Demo，**无真实用户、无上线数据、无商业转化**。
- 不承诺简历通过 ATS 或提高面试成功率。
- 事实校验不能保证 100% 无错误，最终内容以用户人工审核为准。
- API Key 仅存本地；评测样本取自公开 JD，已做脱敏。
